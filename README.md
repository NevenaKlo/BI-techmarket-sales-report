# TechMarket Sales Reporting System

**Author**: [NevenaKlo](https://github.com/NevenaKlo)  
**Project**: Power BI Sales Report for TechMarket S.p.A.

---

## About TechMarket

TechMarket S.p.A. is one of Italy's leading retail chains for consumer electronics, with stores across the country. Managing large volumes of sales data from various points of sale, TechMarket needed an advanced and interactive reporting system to provide detailed insights into their product sales, store performance, and promotional effectiveness.

---

## 🎯Project Objective

The main goal of this project is to develop an **interactive Power BI report** that enables TechMarket decision-makers to:

- Visualize **monthly sales** (accounting for discounts, units sold, and price).
- Analyze **sales performance by city**.
- Monitor **product-level sales metrics**.
- View comprehensive **store-level performance data**.
- Include **returns data** to calculate **net sales** for accurate insights.

---

## 💡 Key Benefits

- **Data-Driven Decisions**: Strategic insights based on accurate, up-to-date data.
- **Promotion Optimization**: Understand which discounts drive the highest ROI.
- **Store Monitoring**: Real-time tracking of each store’s performance.
- **Returns Management**: Refined analysis using net sales (sales minus returns).
- **User-Friendly Report**: Interactive pages and bookmarks for non-technical users.

---

## Project Structure & Data Sources

### 1. Data 

- **Sales Data** containing 2014 monthly sales data.
- **Additional Data**:
  - Store information
  - Product details
  - Italian province data

### 2. Data Transformation

- Merged datasets using Power BI’s **Power Query**.
- Calculated fields like unit price and product description through transformations.

### 3. Report Pages

- **Monthly Sales Overview**: Revenue by month including discount logic.
- **City-Level Sales**: Units sold across different cities.
- **Product Performance**: KPIs for each product.
- **Store Overview**: Store-specific metrics and details.
- **Returns Analysis**: A net sales page for January and February excluding returns.

### 4. Navigation & Interactivity

- Bookmark navigation
- Interactive filters and slicers
- Button-based page switching
